Base de données SQL de suivi de transactions

SQLPostgreSQLMySQLCRUDjointures

Conception d'une base relationnelle (clients, comptes, transactions) et écriture de toutes les requêtes CRUD (CREATE, INSERT, UPDATE, DELETE) ainsi que des analyses avec jointures et agrégations. La démo tourne en SQLite, sans serveur à installer.

Comment ça marche

  • Modélisation : 3 tables liées par clés primaires / étrangères.
  • CREATE des tables + index pour accélérer les recherches.
  • INSERT des clients, comptes et transactions.
  • UPDATE : recalcul des soldes ; DELETE d'une transaction annulée.
  • SELECT avec JOIN et GROUP BY pour les indicateurs.
