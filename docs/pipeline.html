PROJET 03 · Python · ETL

Pipeline de consolidation de données multi-formats

pandasdatatableJSONCSVExcelETL

Mini-ETL : lire trois sources hétérogènes (JSON, CSV, Excel), les nettoyer (doublons, valeurs manquantes), les fusionner par jointures, et exporter un jeu de données consolidé prêt à l'analyse.

Comment ça marche

  • Extract : read_json, read_csv, read_excel.
  • Transform : drop_duplicates et fillna (valeurs manquantes).
  • Fusion : merge (jointures façon SQL) ventes → clients → budget.
  • Load : indicateur CA par segment + export CSV et Excel.

Résultat (exécution réelle du script)

Doublons supprimes : 1 Montants manquants combles : 1 === CA par segment === segment Premium 2000.0 Standard 350.0 Inconnu 150.0 Name: montant, dtype: float64 Exports ecrits : donnees_consolidees.csv / .xlsx

Extrait du code


def nettoyer(clients, ventes):
    """Supprime doublons, gere les valeurs manquantes."""
    avant = len(ventes)
    ventes = ventes.drop_duplicates(subset="vente_id")          # doublon vente_id=3
    print(f"Doublons supprimes : {avant - len(ventes)}")

    # Montant manquant -> 0 (ou on pourrait l'exclure / imputer la moyenne)
    nb_na = int(ventes["montant"].isna().sum())
    ventes["montant"] = ventes["montant"].fillna(0.0)
    print(f"Montants manquants combles : {nb_na}")

    # Segment manquant -> 'Inconnu'
    clients["segment"] = clients["segment"].fillna("Inconnu")
    return clients, ventes


def consolider(clients, ventes, budget):
    """Jointures : ventes -> clients -> budget par segment."""
    df = (ventes
          .merge(clients, on="client_id", how="left")
          .merge(budget, on="segment", how="left"))
    return df
