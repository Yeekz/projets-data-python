Pipeline de consolidation de données

pandasJSON CSVExcellogging

Un pipeline structuré en modules qui consolide trois formats (JSON, CSV, Excel) en un jeu de données propre. Découpage Extract / Transform / Load, avec journalisation et annotations de types.

Architecture du projet

03_pipeline_consolidation/ ├── run.py # orchestration ├── config.py # chemins & paramètres ├── etl/ │ ├── extract.py # lecture JSON / CSV / Excel │ ├── transform.py # dédoublonnage, NaN, jointures │ └── load.py # KPI + export └── sources/ # données d'entrée
Chaque étape (extract / transform / load) est isolée dans son module : plus lisible, testable et remplaçable.
